# ACME Employee Salary Management

Starter repository for the ACME Employee Salary Management project.

## Planned stack

- **Backend:** FastAPI (Python)
- **Frontend:** React with JavaScript
- **Database:** SQLite

## Repository layout

```text
backend/   FastAPI backend
frontend/  React frontend
docs/      Project documentation and requirements
```

The application has not been implemented yet. See [`docs/ACME_Employee_Salary_Management_Requirements.pdf`](docs/ACME_Employee_Salary_Management_Requirements.pdf) for the project requirements.
